## 📌 Overview
This project is a detailed CAD model of an **Inline 4 Cylinder Engine Assembly**, showcasing fundamental mechanical motion and component interaction within an internal combustion engine.

The model demonstrates piston motion, crankshaft rotation, and connecting rod dynamics in a synchronized system.

---

## ⚙️ Key Features
- 4-cylinder inline engine configuration
- Fully constrained mechanical assembly
- Realistic crankshaft and piston movement
- Parametric design approach
- Animated motion study included

---

## 🧩 Components Included
- Engine Block
- Pistons (x4)
- Connecting Rods (x4)
- Crankshaft
- Bearings & Supports
